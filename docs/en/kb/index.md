# FTC knowledge base

Practical guides for **FIRST Tech Challenge** teams, written by the Blades Runners 92 from what we learned setting up our team: what works, the pitfalls, and which versions work together.

They are written first for French-speaking FTC teams, and translated into English for the whole *FIRST* community. Everything is free to read, and [anyone can contribute](contribuer.md).
