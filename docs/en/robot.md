## How we design it

Every mechanism follows the same loop: **analyze the need**, **quick prototype**, **test**, **iterate**. Choices and failed attempts are recorded in our engineering portfolio, which judges review at competitions.

On the software side, the whole team works in a shared GitHub repository, with branches and code reviews: the method is described in [Configuration management](kb/code/gestion-de-configuration.md).
