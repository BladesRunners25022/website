# Base de connaissances FTC

Des guides pratiques pour les équipes **FIRST Tech Challenge**, écrits par les Blades Runners 92 à partir de ce que nous avons appris en montant notre équipe : ce qui marche, les pièges, les versions qui fonctionnent ensemble.

Ils s'adressent d'abord aux équipes FTC francophones, et sont traduits en anglais pour toute la communauté *FIRST*. Tout est libre d'accès, et [chacun peut contribuer](contribuer.md).
