# Outreach

<span class="br-badge">Bientôt</span>

Faire vivre l'équipe au-delà du robot : communication, partenaires, actions auprès du public et des autres équipes.

Les premiers guides de cette rubrique sont en préparation. Quelques sujets que nous aimerions couvrir :

- trouver et fidéliser des partenaires ;
- rédiger le portfolio d'ingénierie ;
- organiser une démonstration ou un atelier découverte ;
- animer les réseaux sociaux de l'équipe sans exposer les élèves.

Vous avez de l'expérience sur un de ces sujets, ou sur un autre ? [Proposez un guide](../contribuer.md).
