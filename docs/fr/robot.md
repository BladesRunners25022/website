## Comment on le conçoit

Chaque mécanisme suit le même cycle : **analyse du besoin**, **prototype rapide**, **essai**, **itération**. Les choix et les essais ratés sont consignés dans notre portfolio d'ingénierie, qui est évalué par le jury en compétition.

Côté code, toute l'équipe travaille sur un dépôt GitHub partagé, avec des branches et des relectures : la méthode est décrite dans [Gestion de configuration](kb/code/gestion-de-configuration.md).
